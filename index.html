Задание B7-B8: Устойчивые выражения с общим словом

📖 Словарь устойчивых выражений

В задании B7-B8 нужно найти слово, которое подходит к двум разным контекстам. Вот все комбинации из сборника:

lose weight / lose a game
сбросить вес / проиграть игру
run the risk / run a company
рисковать / управлять компанией
set off early / set the alarm clock
отправиться в путь рано / завести будильник

1 Найдите общее слово

Впишите глагол, который объединяет два выражения (в начальной форме, например: lose, run, set).

1. ____ weight / ____ a game
2. ____ the risk / ____ a company
3. ____ off early / ____ the alarm clock

2 Поставьте в правильную форму

Измените форму глагола так, как это требуется в сборнике (например, lost, was running, has set).

1. lose weight / lose a game -> has ___
2. run the risk / run a company -> we ___
3. set off early / set the alarm clock -> we ___ off / was ___
4. lose weight / lose a game -> is ___
5. run the risk / run a company -> had ___
